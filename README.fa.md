# 🏛️ سامانه جامع مدیریت حوزه علمیه و مراکز حوزوی

سامانه یکپارچه، پیشرفته و امن مدیریت آموزشی، مالی، تربیتی و اداری حوزه‌های علمیه، مبتنی بر معماری فول‌استک **React 19 + TypeScript + Express + Vite** و پایگاه داده رابطه‌ای **MySQL 8 / PostgreSQL**.

---

## 🌟 امکانات و ماژول‌های سامانه

1. **احراز هویت و امنیت ۳ سطحی (RBAC):**
   - **سطح ۱ (مدیران ارشد):** سوپرادمین، مدیر مدرسه، معاونین (کنترل کلیه دسترسی‌ها، پشتیبان‌گیری، لاگ‌های سیستمی).
   - **سطح ۲ (مسئولین واحدها و اساتید پایه):** مسئول آموزش، مسئول مالی، اساتید پایه‌های ۷، ۸، ۹، ۱۰، مسئول پژوهش.
   - **سطح ۳ (طلاب و اساتید):** ثبت فعالیت‌های فردی، رزرو وعده‌های غذایی، سامانه درخواست‌های کتبی، مشاهده نمرات و کارنامه.

2. **سامانه پیشرفته درخواست‌های اداری و رفاهی طلاب:**
   - ثبت آنلاین درخواست در ۳ بخش: آموزش و امتحانات، مالی و وام‌ها، فرهنگی و رفاهی.
   - امکان فعال/غیرفعال کردن حالت پاسخگویی توسط مسئول هر واحد به صورت کاملاً مستقل.
   - امکان مخفی‌سازی سراسری پنل برای طلاب سطح ۳ توسط سوپرادمین.
   - ثبت پاسخ رسمی، دلایل رد یا تایید درخواست، همراه با تاریخ و نام مسئول.
   - نمایش نشان و بج چشمک‌زن ویژه در منوی نرم‌افزار به محض دریافت تقاضای جدید.

3. **مدیریت امور مالی، شهریه و وام‌ها:**
   - محاسبه خودکار شهریه طلاب بر اساس ساعات مطالعه، حضور، امتحانات و نمرات.
   - صندوق قرض‌الحسنه و مدیریت اقساط وام‌های فعال.
   - ثبت اسناد هزینه، تنخواه، و گزارش تفکیکی ردیف‌های بودجه.

4. **مدیریت فیزیکی ۲۰۰ کمد طلاب:**
   - نمای ماتریسی ۲۰۰ کمد، وضعیت خالی، پر و معیوب.
   - تاریخچه واگذاری، جابجایی، ثبت کلید یدک و گزارش خرابی قفل.

5. **امنیت چندلایه و ضد دستکاری:**
   - کد پین امنیتی ادواری (Session Escalation PIN).
   - امضای دیجیتال برای جلوگیری از تغییر متغیرها از طریق Inspect Element / F12.
   - زنجیره هش رمزنگاری‌شده لاگ‌ها (Hash Chain Audit Trail) غیرقابل بازگشت و مقاوم در برابر دستکاری دیتابیس.
   - سیستم هوشمند کشف ناهنجاری‌ها و امکان بازگردانی داده‌ها با یک کلیک (Instant Rollback).

## 🚀 راهنمای نصب و راه‌اندازی سریع

### ۱. پیش‌نیازها
- Node.js نسخه 18 یا بالاتر (نسخه پیشنهادی: Node.js 22 LTS)
- پایگاه داده MySQL نسخه 8.0 یا PostgreSQL

### ۲. نصب پکیج‌ها
```bash
npm install
```

### ۳. تنظیم فایل محیطی
```bash
cp .env.example .env
```
مقادیر `JWT_SECRET` و `JWT_REFRESH_SECRET` و اتصال پایگاه داده را تنظیم فرمایید.

### ۴. راه‌اندازی دیتابیس
اسکریپت `database_complete.sql` را در MySQL اجرا فرمایید:
```bash
mysql -u root -p madrasah_db < database_complete.sql
```

### ۵. اجرای پروژه در حالت توسعه
```bash
npm run dev
```
پروژه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

## 🛠️ دستورات خط فرمان

- `npm run dev`: اجرای سرور در حالت توسعه
- `npm run build`: کامپایل و بیلد نسخه پروداکشن کلاینت و سرور
- `npm run start`: اجرای نسخه بیلد شده روی سرور یا هاست
- `npm run lint`: بررسی خطاهای تایپ‌اسکریپت
